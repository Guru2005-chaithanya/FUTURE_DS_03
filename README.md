# Marketing Funnel & Conversion Performance Dashboard

## Project Overview
This project analyzes marketing funnel performance using Power BI.  
The dashboard tracks lead generation, conversion rates, funnel drop-offs, and monthly trends to provide business insights.

## Tools Used
- Power BI
- DAX
- CSV Dataset

## Dataset
- Olist Marketing Qualified Leads Dataset
- Olist Closed Deals Dataset

## Dashboard Features
- KPI Cards
- Advanced Funnel Analysis
- Conversion Rate Analysis
- Lead Source Performance
- Drop-Off Analysis
- Monthly Trend Analysis

## Key Insights
- Significant funnel drop-offs were identified between qualification and contact stages.
- Certain lead sources generated higher quality leads.
- Monthly trends showed fluctuations in lead acquisition performance.
